# Media

This is me my "media grabbing" suite.

1. The *arr apps crawl trackers for media and send requests for the media to qBittorrent
2. qBittorrent retrieves them
3. The *arr apps then hardlink them into Jellyfin's media library directory
4. Then you can watch the media in Jellyfin! 🪼🍿

I followed [TRaSH Guides](https://trash-guides.info/Hardlinks/How-to-setup-for/Native/) to get this all working with hardlinks.
